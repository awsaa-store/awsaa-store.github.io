# AWSAA · دليل المنتجات

صفحة بحث لمنتجات المخزن (240 منتج) بالصورة والاسم، ومكان كل منتج: **الرف (مثلاً A1) · الدرج (من تحت لفوق) · البوكس**.

- `index.html`: الصفحة
- `img/`: صور المنتجات (p001.jpg … p240.jpg)
- `products.csv`: رقم واسم كل منتج، ويقرأه جدول قوقل للأماكن

الأماكن تتعبى في جدول قوقل، والصفحة تقراها روحها كل دقيقتين.
